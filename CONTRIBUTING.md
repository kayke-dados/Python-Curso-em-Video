# Contribuindo

Este é um repositório pessoal de estudos. Sugestões de melhoria são bem-vindas, mas o histórico dos exercícios é preservado.

## Regra principal

Não altere, corrija, renomeie ou complete os exercícios existentes. Eles registram o que foi escrito em cada etapa do aprendizado.

## Como sugerir algo

- Abra uma issue descrevendo a sugestão.
- Para erros de documentação, indique o arquivo e o trecho.
- Não envie alterações que modifiquem o conteúdo dos exercícios.

## Verificações locais

```bash
python3 tools/verify_exercises.py
python3 tools/check_repository.py
python3 -m unittest discover -s tests -v
```
