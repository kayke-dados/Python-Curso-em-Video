## O que é este espaço

Este capítulo ainda não tem exercícios. Ele está reservado para o que vem depois dos fundamentos de Python.

A pasta `07-proximos-aprendizados/` existe para não misturar conteúdos futuros com o histórico do curso. Quando um tema começar, ele ganha uma subpasta e um README próprio.

## Temas planejados

- projetos completos que juntem vários capítulos
- programação orientada a objetos
- bancos de dados com SQLite
- desenvolvimento web com Python

## Regra para quando começar

- só criar exercícios depois de estudar o conteúdo;
- registrar o progresso real, sem marcar como concluído antes da hora;
- atualizar o [roadmap](../ROADMAP.md) e o [diário](../STUDY-LOG.md).

## Como executar

Não há exercícios nesta pasta ainda. Quando houver:

```bash
python3 "07-proximos-aprendizados/<tema>/<arquivo>.py"
```

## Por que este capítulo existe

Ele deixa claro que a jornada continua. O objetivo não é transformar o repositório em um curso completo, e sim registrar a evolução real, etapa por etapa.
