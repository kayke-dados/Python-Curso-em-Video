## Como atualizar este roadmap

1. Só marcar uma etapa como concluída quando houver exercícios ou projetos que a comprovem.
2. Se a etapa estiver em andamento, explicar qual parte já foi praticada.
3. Registrar o marco no [STUDY-LOG.md](STUDY-LOG.md).
4. Atualizar a tabela de progresso do [README](../README.md), se necessário.
