## Como registrar um novo marco

1. Adicione uma linha na tabela com a data real.
2. Descreva o que foi feito em uma frase objetiva.
3. Aponte a evidência: commit, exercício ou documento.
4. Atualize o [roadmap](ROADMAP.md) se o status de uma etapa mudar.

> Não registre um estudo que ainda não gerou exercício ou documento. O diário deve refletir o que existe.
